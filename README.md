# 🛒 Target Business Case Study (SQL)

## 📌 Project Overview
This project analyzes Target's sales dataset using SQL to solve real-world business problems and generate data-driven insights. The analysis focuses on customer behavior, sales trends, order performance, and business metrics to support strategic decision-making.

---

## 🎯 Objectives
- Analyze customer purchasing behavior.
- Evaluate sales performance.
- Identify top-performing products and categories.
- Study order and payment trends.
- Generate actionable business recommendations.

---
